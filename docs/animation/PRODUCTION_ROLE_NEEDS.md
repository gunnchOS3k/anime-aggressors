# Production Role Needs — Authored Animation

Automation built the pipeline. Humans must fill the acting.

| Role | Headcount (min) | Owns | Gate they may set |
|------|-----------------|------|-------------------|
| Animation director | 1 | Style, pose bible sign-off, clash readability | `HUMAN_ANIMATION_QUALITY_PASS` (with combat director) |
| Combat animator | 2–3 | Wave A 98 hero actions, contact / hurt / charge | none alone |
| Technical animator | 1 | Rig weights, export, Godot import, event markers | `AUTHORED_EXPORT_IMPORT_PASS` evidence only |
| Combat designer (existing) | — | Frame data stays locked; flags late animation | none |
| Aura / VFX artist | 1 | Clash mixed-identity, charge presence | `HUMAN_AURA_CLASH_PASS` with director |
| Camera / cinematic | 0.5 | Class shots, a11y reduce-camera | none |
| Human playtest owner | 1 | Pixel 6a feel, clip-worthy moments | `HUMAN_COMBAT_FEEL_PASS`, `HUMAN_CLIP_WORTHY_PASS` |
| Merge owner | 1 | Release | `MERGE_AUTHORIZED` |

## This pass explicitly does **not** staff

- Motion-capture cleanup as a substitute for authored hero acting
- Procedural clip farms
- Franchise choreography reference tracing
