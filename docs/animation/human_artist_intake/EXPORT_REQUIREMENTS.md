# Export requirements

Preset: `art_source/animation/shared/export/EXPORT_PRESET.json`

- glTF 2.0 binary `.glb`
- Include mesh, deform skeleton, skins, animations
- Apply modifiers
- 60 fps
- One clip per file for hero actions, or one file with correctly named actions
- No copyrighted third-party meshes
- No baked gameplay root motion
- Blender 3.3.1 preferred (`BLENDER_BIN`)

Destination for candidates: `game-godot/content/human_art_staging/<fighter-id>/`
