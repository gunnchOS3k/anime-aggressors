# Full-roster production brief

Owner decision: the Rook/Nix Golden Slice is **replaced** by a seven-fighter production-art plan.

Do not bind V9 / generated-experiment geometry. Gameplay, CombatMath, hitboxes, and physics stay on accepted main.

Logical IDs (do not rename):

`ember-vale` `rook-ironside` `juno-spark` `kaia-windrow` `nix-calder` `orion-vell` `vesper-nyx`

## Shared constraints

- Faceless abstract heads. Expression through posture, costume, and aura.
- Canonical deform skeleton only. See `SKELETON_CONTRACT.md`.
- Required sockets named exactly. See `SOCKET_CONTRACT.md`.
- Original IP only. No franchise crests, haircuts, gis, or licensed silhouettes.
- Root motion is presentation-only. The game moves the fighter.
- Soft cap: 12 materials. Report triangle count. Do not invent a quality score.
- Mobile readability: silhouette must read at Pixel gameplay scale (~1.7–1.9 m stylized).
- Bind to `HUMAN_CANDIDATE` staging. Automation never sets `HUMAN_APPROVED`.

## Minimum Pixel review subset (every fighter)

production mesh/rig, idle, walk, run, charged idle, heavy, hurt-heavy, launch/tumble, super hero pose, clash lock

## Full production package (later)

See `full_roster_source_package/FULL_PRODUCTION_ACTION_LIST.md`.
