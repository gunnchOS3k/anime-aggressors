# V4.2 Roster Visual Language

Shared grammar:
- dark readable combat base
- fighter-specific power architecture
- cel-shaded material system
- progressive aura transformation (BASE→CHARGED→SURGE→ASCENDANT→SUPER)

Rule: every fighter is an original physical embodiment of the entire power lane, not a person wearing an elemental costume.

Body variants are presentation-only. Gameplay, skeleton bone names, action IDs, sockets, hitboxes, frame data, and PartyLink identity remain shared.

Human visual approval gates remain false until owner review.
