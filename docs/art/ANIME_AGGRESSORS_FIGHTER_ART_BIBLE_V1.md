# Anime Aggressors — Fighter Art Bible v1

## North-star
Keep the current expressive compact body-shape direction, but move from “costumed toy” to **stylized elemental combatant**. The roster should feel like one game, with each fighter embodying a different force.

## Roster-wide visual grammar
- Compact, readable bodies; slightly oversized hands/head for mobile readability, but not bobblehead.
- One shared cel-shaded rendering language across all 7.
- Elemental material identity must live in the body, not only in particles.
- At least 3 meaningful non-emissive value groups per fighter.
- VFX amplifies body acting; it never replaces it.
- Strong hits must read with VFX OFF.
- No photoreal faces; preserve stylized/abstract head direction.
- References are principle references only; do not copy copyrighted costumes, silhouettes, logos, signature poses, or attacks.

## Color/material lock
- **Ember:** molten core + charcoal structure + hot yellow/white seams.
- **Rook:** dense dark iron/stone + muted metallic secondary + restrained impact glow.
- **Juno:** dark electric body + yellow kinetic panels + cyan-white current.
- **Kaia:** dark teal core + pale air panels + bright airflow accents.
- **Nix:** dark cold core + pale ice armor + cyan crystal edge.
- **Orion:** deep-space body + violet structure + constellation/starlight network.
- **Vesper:** dark void core + plum cowl/structure + pale phase edges.

## Review truth test
For every fighter, with VFX OFF, pause at:
- anticipation
- contact
- peak hurt
- charged idle
- super
- clash

Ask:
1. Who is attacking?
2. Which direction?
3. What element/force is this fighter?
4. Does the pose alone communicate power?
5. Does the defender visibly react before launch?
6. Does the silhouette remain distinct on Pixel?

If not, revise before adding more particles.
