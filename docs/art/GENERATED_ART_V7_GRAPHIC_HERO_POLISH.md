# Generated Art v7 — Graphic Hero Polish

Keeps the v6 **graphic faceless combat** style lock. This pass is polish, not a
new art direction.

Generated production art only. Not human-authored final art.

## Still locked

- full-body undersuits (never peach/clay)
- faceless masks / helmets / cowls
- stylized glove families
- integrated boot families
- large costume masses
- hard palette blocking
- cel shading
- no voxel remesh
- no realistic faces

## v7 polish goals

1. Value groups stay readable with emission off. Nix is dark-suit / pale-armor.
2. Detail cameras show the whole glove/boot/head/costume, not a crop.
3. Gloves and boots read at gameplay scale.
4. Each fighter has a hero costume feature that survives mobile size.
5. Idle / walk / run / dash communicate identity.
6. Heavy review is a contrasting attacker/defender pair.
7. Hurt, charge, super, and clash acting are posed, not T-pose overlays.

## Human gates

`HUMAN_*`, `MERGE_AUTHORIZED`, and `FINAL_AUTHORED_ANIMATION_PASS` stay false
until a human actually approves.
