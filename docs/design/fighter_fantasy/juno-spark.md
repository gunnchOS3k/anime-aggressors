# Juno Spark — Fighter Fantasy

**Lane:** electricity / lightning / speed / magnetism  
**Aura grammar:** confirms

## Fantasy statement

Juno is snap confirmation and volt trails. Attacks should feel instantaneous confirms with afterimage residue. Projectiles read as **arc bolts / capacitor discharges**, sharp and brief—not soft colored boxes.

## Presentation priorities

1. Compact core + capacitor spines  
2. Snap poses distinct from Ember lean / Rook plant  
3. Volt VFX secondary, high-contrast lane accents
