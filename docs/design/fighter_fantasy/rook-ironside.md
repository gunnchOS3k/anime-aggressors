# Rook Ironside — Fighter Fantasy

**Lane:** impact / strength / earth / quake / armor  
**Aura grammar:** armors through

## Fantasy statement

Rook sells planted weight and basalt durability. Motion is ground-coupled; hits feel heavy and delayed. Projectiles / shockwaves should read as **seismic / rubble / armored bursts**, never light neon rectangles.

## Presentation priorities

1. Wide stance silhouette  
2. Armor readable before VFX  
3. Impact VFX secondary, earth-lane palette
