# Vesper Nyx — Fighter Fantasy

**Lane:** void / darkness / shadow / phase / intangibility  
**Aura grammar:** misdirects

## Fantasy statement

Vesper misdirects with phase cancels and presence drops. Projectiles / voids should read as **phase rifts / shadow bites**, deep and deceptive—not bright debug boxes.

## Presentation priorities

1. Hood + void cape silhouette distinct  
2. Misdirection readable without UI crutches  
3. Void VFX secondary
