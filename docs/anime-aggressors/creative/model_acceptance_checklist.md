# Model acceptance checklist

Doctrine. Checking these boxes in a review does not set `HUMAN_ART_APPROVAL`.

For each presentation (fighter × form):

- [ ] Named from silhouette with the color channel removed
- [ ] Modeled face, not a box, not a skull (unless this row is a puppet mask)
- [ ] Hair or crest is geometry or cards, and it moves
- [ ] Male mesh and female mesh both exist for base forms
- [ ] Match-camera body height is in the readability band in the model bible
- [ ] Element accent does not replace the body
- [ ] Idle, light, heavy, special, hurt, and victory change the silhouette
- [ ] Side-by-side with the V4.5 board, an outside reviewer agrees it is the same person
- [ ] Puppet or Gray row is flagged story-only
- [ ] No player-facing art-source overlay

Current Kaia, Yin, and Yang block bodies: fail. Do not promote them by partial credit.
