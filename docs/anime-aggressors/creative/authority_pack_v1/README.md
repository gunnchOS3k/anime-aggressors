- `references/` — supplied V4.5 visual boards

## Authority convention

This package distinguishes:

- **SOURCE-DERIVED CANON** — directly supported by the supplied V4.5 boards, movement/animation bible, fighter production bibles, and prior story notes.
- **PRODUCTION DECISION V1** — a concrete implementation/design rule synthesized here to make the source material buildable. Treat as owner-approval canon.
- **OPEN CANON DECISION** — source material intentionally does not settle the point; do not silently invent it.
- **IMPLEMENTATION TRUTH** — creative target does not imply the current game has already achieved it.

## Core rule

Anime Aggressors is not a roster of meshes with effects.

Each fighter is a **motion identity** whose model, silhouette, animation, VFX, audio, dialogue, and story arc must all communicate the same character.
